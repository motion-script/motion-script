# Code

The `Code` node renders syntax-highlighted code using [Lezer](https://lezer.codemirror.net/). Grammars are loaded lazily per language, and built-in themes are provided. It offers animation methods for highlighting, replacing, inserting, and removing code.

Every edit is animated by **diffing** the listing against the source it becomes: tokens that survived the edit keep their identity and travel to their new columns, what is gone fades out first, and only then does what is new arrive.

Supported languages: `typescript`, `tsx`, `javascript`, `jsx`, `python`, `json`, `html`, `css`, `rust`, `go`, `java`, `cpp`, `php`, `markdown`, `xml`, and `yaml`.

<CodeCanvas />

`Code` ships as a registry component, not a package dependency: `ms add` copies
its source straight into your project, so you can read and edit it like any
other file you own.

Add the component to your project:

```bash
ms add code
```

## Basic usage

```tsx
import { createScene, createRef } from 'motion-script';
import { Code, lines, word } from '@/components/code';

export default createScene(function* (stage) {
  const ref = createRef<Code>();

  stage.add(
    <Code
      ref={ref}
      code={`function greet(name: string) {
  return \`Hello, \${name}!\`;
}`}
      fontSize={28}
      showLineNumbers={true}
    />
  );

  yield* ref().highlight(lines(2), 0.5);
});
```

## Props

| Prop | Type | Description |
|---|---|---|
| `code` | `string` | Source code to display |
| `fontSize` | `number` | Font size in pixels |
| `showLineNumbers` | `boolean` | Show line number gutter |

The highlighted language and color theme are configured via the `@motion-script/code` package settings. Themes are Lezer-based highlight styles (e.g. `github-dark`, `github-light`, `vscode-dark`, `vscode-light`) rather than Shiki themes.

## Animating to new code

The simplest way to change a listing is to tween `code` like any other prop:

```tsx
yield* ref().to({
  code: `function greet(name: string) {
  return \`Hi, \${name}.\`;
}`,
}, 1.2);
```

The node works out the difference for you. In the example above `function greet(name: string) {` and the closing brace never move, `Hello,` fades out where it stood, and `Hi,` fades in once the rest of the line has finished reflowing around it.

New **rows** enter from the direction they arrived from — a row appended below the listing rises into place, a row inserted above it descends, and a row spliced between two existing rows slides in from the left. A row always moves as one piece.

The named methods below are the same engine, expressed as an edit rather than as a whole document. Use whichever reads better: `to({ code })` when you have the finished source, a named edit when the interesting thing is the edit itself.

## Animation methods

Each returns a `Command`, which can be `yield*`-ed like a generator or placed on a timeline.

### `highlight(range, duration, easing?)`

Visually highlight a range of code:

```tsx
yield* ref().highlight(lines(2), 0.5);
yield* ref().highlight(word(3, 10, 9), 0.4);  // line 3, col 10, length 9
```

### `resetHighlight(duration, easing?)`

Remove all highlights:

```tsx
yield* ref().resetHighlight(0.3);
```

### `replace(range, text, duration, easing?)`

Replace a range of code with new text:

```tsx
yield* ref().replace(word(1, 22, 6), 'string', 0.3);
```

### `erase(range, duration, easing?)`

Remove a range of code with an animated transition. A range covering whole lines
takes their line breaks with it, so the rows below close up; a range inside a
line takes only the characters, and the rest of the line reflows around the hole:

```tsx
yield* ref().erase(lines(2), 0.4);       // the row disappears
yield* ref().erase(word(1, 14, 3), 0.4); // the line closes over the gap
```

### `insert(position, text, duration, easing?)`

Insert code at a 1-indexed `[line, column]`. The column is the one the new text
is inserted *before*, so `1` is the start of the line:

```tsx
yield* ref().insert([1, 15], 'name: string', 0.5);
```

### `append(text, duration, easing?)` / `prepend(text, duration, easing?)`

Add code below or above the listing. Because the whole document is
re-highlighted, a line that closes a block re-colours the lines above it:

```tsx
yield* ref().append('\ngreet("world");', 0.6);
yield* ref().prepend('import { greet } from "./greet";\n\n', 0.6);
```

## Range helpers

Import range helpers from `@/components/code`:

```tsx
import { lines, word } from '@/components/code';

// Select line 2 (1-indexed)
lines(2)

// Select lines 2 through 5
lines(2, 5)

// Select a word: line 3, starting at column 10, length 9
word(3, 10, 9)
```

## Full example

```tsx
import { createScene, createRef, wait, parallel, easeOut } from 'motion-script';
import { Code, lines, word } from '@/components/code';

export default createScene(function* (stage) {
  const ref = createRef<Code>();

  stage.add(
    <Code
      ref={ref}
      code={`function getUser(id: number) {
  const user = db.find(id);
  return user.name;
}`}
      fontSize={32}
      showLineNumbers={true}
    />
  );

  yield* wait(0.5);

  // Highlight line 2
  yield* ref().highlight(lines(2), 0.5);
  yield* wait(0.6);

  // Highlight a specific word
  yield* ref().highlight(word(3, 10, 9), 0.4);
  yield* wait(0.6);

  // Clear highlight
  yield* ref().resetHighlight(0.4);
  yield* wait(0.3);

  // Replace a token
  yield* ref().replace(word(1, 22, 6), 'string', 0.3, easeOut('quad'));
  yield* wait(0.5);

  // Remove a line
  yield* ref().erase(lines(2), 0.4);
  yield* wait(1);
});
```
