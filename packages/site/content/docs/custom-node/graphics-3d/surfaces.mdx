# 2D on 3D

`Tex.surface` renders 2D MotionScript content into an offscreen buffer and binds it to any material map. It is how you put a chart on a monitor, a label on a sign, or a whole layout on a curved panel.

```tsx
import { Graphics2D, Tex, Canvas3D, PerspectiveCamera3D, AmbientLight3D, Plane3D } from 'motion-script';

const panel = new Graphics2D()
  .rect({ width: 512, height: 512 })
  .fill('#101826')
  .rect({ x: 0, y: 96, width: 384, height: 160 })
  .fill('#4f8ef7');

<Canvas3D>
  <PerspectiveCamera3D position={[0, 0, 4.2]} lookAt={0} fov={45} />
  <AmbientLight3D intensity={0.8} />
  <Plane3D width={3} height={3} map={Tex.surface(panel, 512, 512)} unlit />
</Canvas3D>
```

## The source is a value

`Tex.surface(source, width, height, options?)` takes two kinds of source:

* A built [`Graphics2D`](../graphics/overview), for anything you can draw directly.
* A `Node2D` subtree, for anything that needs real layout, shaped `Text` or a loaded `Image`.

```tsx
const scope = new Graphics2D().line({ points: trace }).stroke({ weight: 6, fill: '#6990DD' });
const stats = <Rect flow="vertical" padding={48} gap={16}>
  <Text text="CPU" fontSize={64} fill="white" />
  <Text text="42%" fontSize={96} fill="#6990DD" />
</Rect>;

<Canvas3D>
  <Plane3D map={Tex.surface(scope, 1024, 640)} />
  <Plane3D map={Tex.surface(stats, 1024, 640)} position={[5, 0, 0]} />
</Canvas3D>
```

A node source does not have to live anywhere in the scene tree. It is a value in a descriptor, so `Canvas3D` hands it the asset catalog, context and clock it would otherwise get from a parent.

`width` and `height` are the buffer's resolution in pixels, and they also set the panel's aspect. Match your plane's proportions to them or the texture will stretch.

## Hoist the source

Build the source once, outside any per-frame binding. Rebuilding it every frame re-lays-out the subtree, defeats the texture cache, and leaks.

```tsx
// Right: built once, at module or scene scope
const panel = new Graphics2D().rect({ width: 512, height: 512 }).fill('#101826');

<Canvas3D>
  <Plane3D map={Tex.surface(panel, 512, 512)} />
</Canvas3D>
```

```tsx
// Wrong: a fresh source every frame
<Canvas3D>
  <Plane3D map={() => Tex.surface(new Graphics2D().rect({ /* ... */ }), 512, 512)} />
</Canvas3D>
```

The source itself can still animate. A `Graphics2D` source built from signals is fine, because the value changes while the identity stays put.

## Give a conditional surface a key

The texture cache is global. If a surface is emitted conditionally, its position in the scene can shift between frames, which orphans the old texture instead of reusing it. Pass an explicit `key`:

```tsx
screens.forEach(screen => {
  g3.plane({
    width: 4,
    height: 4 * (screen.height / screen.width),
    map: Tex.surface(screen.source, screen.width, screen.height, { key: screen.id }),
  });
});
```

## Options

`Tex.surface` takes all the [texture options](./materials#textures), plus:

| Option | Type | Description |
|---|---|---|
| `key` | `string` | Stable identity for the texture cache |
| `maxPixelRatio` | `number` | Ceiling on the buffer's device-pixel ratio. Default 1 |

## Use an unlit material for screens

A screen should read as its own light source. A lit material tints the texture with the scene's lighting and looks muddy:

```tsx
<Plane3D width={width} height={height} position={[0, 0, 0.095]} unlit map={Tex.surface(source, w, h)} />
```

## Cost

The 3D renderer owns its own graphics context, so there is no shared texture. Every animated surface costs a full read back from the GPU plus an upload, once per frame. That is why the default pixel ratio is 1.

Practical consequences:

* Keep buffer resolutions as small as the content allows.
* A static surface is much cheaper than an animated one, because the cache can hold it.
* A handful of surfaces is fine. Dozens of animated ones will not be.

## A worked example

A rig of monitors, where the node owns the hardware and the scene owns the content:

```tsx
interface Screen {
  id: string;
  source: SurfaceSource3D;
  width: number;
  height: number;
}

function monitor(screen: Screen, x: number) {
  const width = 4;
  const height = width * (screen.height / screen.width);

  return (
    <Group3D position={[x, 0.35, 0]}>
      <Box3D
        width={width + 0.24} height={height + 0.24} depth={0.18}
        color="#15181f" roughness={0.55}
      />
      <Plane3D
        width={width} height={height}
        position={[0, 0, 0.095]}
        unlit
        map={Tex.surface(screen.source, screen.width, screen.height, { key: screen.id })}
      />
    </Group3D>
  );
}

function monitorWall(screens: Screen[], spacing = 6) {
  const half = ((screens.length - 1) / 2) * spacing;

  return (
    <Canvas3D width="fill" height="fill">
      <PerspectiveCamera3D position={[0, 1, 13]} lookAt={[0, 0.2, 0]} fov={42} />
      <Background3D background="#080a10" />
      <AmbientLight3D intensity={0.5} />
      <DirectionalLight3D intensity={1.8} position={[5, 8, 6]} />
      <PointLight3D intensity={40} position={[0, 1, 5]} color="#5f7fd0" />

      {screens.map((screen, i) => monitor(screen, i * spacing - half))}
    </Canvas3D>
  );
}
```

Adding a third monitor is adding a third entry — and because each monitor's cache identity is its own node, adding one leaves the others' GPU objects untouched. The panel takes each buffer's own aspect, so a screen authored at any resolution shows its texture unstretched.
